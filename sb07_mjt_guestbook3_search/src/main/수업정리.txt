4. Querydsl 설명
	1) Querydsl 은 JPA에서 SQL이나 JPQL을 자바코드로 안전하고 편하게 잓어하기
	 	sql: select * from guestbook
	 	jpql: select g from Guestbook g
	 	-> sql/jpql을 자바코딩으로 쿼리작성해주는 도구....
	2) 예시
	@Query("select d from Dept d where d.dname = :dname")
	List<Dept> findByDname(@Param("dname") String dname);
	=> Querydsl 사용
	QDept dept = QDept.dept;		//from dept

	List<Dept> list =
	    queryFactory
	        .selectFrom(dept)	//select d from
	        .where(dept.dname.eq("SALES"))	//where d.dname = :dname
	        .fetch();
	        
	3) 검색조건이 복잡해지면 jpql은 복잡해진다.
		그래서 동적쿼리 같은 검색조건이 복잡할 경우에는 Querydsl을 사용하면 편리하다.
		
	4) Querydsl의 가장 중요한 특징: Q 클래스				Q 클래스
	@Entity Dept -> Querydsl의 annotation processor -> QDept 
	
	5) Querydsl의 기본 구조...
		(1)JPAQueryFactory queryFactory;
		(2)전체흐름:
					Entity
					  ↓
					QEntity 생성
					  ↓
					QDept	Q클래스
					  ↓
					JPAQueryFactory : Querydsl에게 이렇게 실행해라는 명령 객체.
					  ↓
					 자바코딩
					select()
					from()
					where()
					orderBy()
					  ↓
					fetch()
					
	6) Querydsl 의 매우 중요한 장점: 동적 쿼리
	
	7) Querydsl의 전체 구조:
					        Entity
				               │
				               ▼
				             Dept
				               │
				               │ Querydsl
				               ▼
				             QDept
				               │
				               ▼
				        JPAQueryFactory
				               │
				       ┌───────┼────────┐
				       ▼       ▼        ▼
				    select    where   orderBy
				       │       │        │
				       └───────┼────────┘
				               ▼
				             fetch()
				               │
				               ▼
				          List<Dept>
