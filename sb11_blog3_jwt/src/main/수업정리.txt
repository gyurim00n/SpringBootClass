	1) 토큰 기반 인증이란..?

	2)토큰을 전달하고 인증받는 처리 과정 이해.
	3)토큰 기반 인증의 특징?
		1)무상태성: 서버에 인증 정보 X ~~ 서버의 자원을 이용할 필요 x (클라이언트에 저장된다.
		2)확장성: 서버 + 서버 + .... => 인증처리 신경 x.
		3)무결성: 토큰 발급 후 토큰 정보를 변경하는 행위 할 수 없다.
	4)JWT
		1)요청 해더 중에 Authorization 키값에 Bearer + "JWT 토큰값"
		2) 토큰 구조 : 헤더, 페이로드, 서명
						토큰 내용의 한 덩어리: 클레임(claim)
